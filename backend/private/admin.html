PriceCharting details cache

Sold listings and graded guides. Separate from TCG listing prices. Saves every 1000 cards (gzip + fail-links to R2). The denominator is the full English catalog — many cards are missing on PriceCharting, so the cache often stays well below 100%. Each finished set gets a timestamp in the dropdown. Starting this while TCG is running will stop and save TCG first.
